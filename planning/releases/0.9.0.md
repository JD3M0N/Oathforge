# Oathforge 0.9.0 — entrega y anuncios

## Operación

1. Guardar copia de PostgreSQL antes de aplicar `alembic upgrade head`.
2. Ejecutar `oath achievements-backfill` (simulación) y revisar el informe.
3. Ejecutar `oath achievements-backfill --apply`; admite `--character-id ID` y `--after-id ID` para procesar o reanudar.
4. Arrancar el bot y comprobar /achievements, /hero y /journal.
5. No degradar la migración después de conceder logros: la degradación elimina las tablas de logros. Restaurar una copia o volver al código anterior manteniendo el esquema aditivo.

Los anuncios pendientes usan una concesión de envío de 120 segundos. Un corte después del envío y antes de confirmar puede repetir el mensaje; nunca duplica los logros ni los puntos. La próxima interacción privada recupera anuncios pendientes. No se envía nada a grupos ni canales automáticamente.

Los encuentros iniciados antes de 0.9 conservan su funcionamiento y no certifican desafíos que requieren métricas nuevas. El backfill reconoce fechas de concesión actuales y marca su origen retroactivo. No deduce apertura del relicario a partir del final independiente, recetas a partir de objetos ni caza nocturna a partir del bestiario.
